# Constrained noisy networks

Code and numerical results for **“When hard constraints meet: effective resistance and stationary disagreement in noisy networks”**, by Junkee Jeon and Yeoneung Kim.

The scripts investigate a network of linearly coupled diffusions confined to individual intervals. They include exact two-node calculations, stationary samplers, a Gibbs check for an incompatible cycle, and simulations of reflected dynamics.

## Contents

- `code/` — experiment, sampling, verification, and figure scripts.
- `code/results/` — the saved numerical results reported in the manuscript, including the two-node intermediate array and the incompatible-cycle batch estimates.
- `figs/` — the figure PDFs included in the manuscript.

The saved JSON files contain reported numerical results; `two_node.npz` supports Figure 3. The repository also includes `spatial.npz`, regenerated on 2026-11-05 with the tested Python 3.9 environment below and the original experiment seed. Its rounded slopes, maximum deviation and largest standard error agree with the values reported for Figure 6. It is a new run, not the archived input to the original figure PDF; the original input was not retained, so exact pointwise identity cannot be verified. Other intermediate NPZ arrays used by the figure scripts are not included and must be regenerated by running the corresponding experiments. The existing PDFs can be inspected without rerunning the simulations. Regeneration may produce small numerical or rendering differences across environments.

## Setup and quick check

The following environment was used for the cycle check, Figure 3, and the validation script. A compatible Python 3.9 installation is required.

```bash
cd code
python3.9 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-tested.txt
python verify_results.py
```

`verify_results.py` checks selected response-function identities, the cycle's deterministic and grounded-covariance calculations, saved cycle batches, two-node values, and the reported Figure 6 summary statistics against the regenerated spatial data. It does not rerun all experiments. To regenerate Figure 3 from the included array, run `python fig3.py` from `code/`.

The original experiments were recorded with Python 3.13, NumPy 2.5.3, SciPy 1.18.1, and NetworkX 3.7; these versions are listed in `requirements-original.txt`. The original Matplotlib version was not recorded. Most figures use the PGF/LaTeX backend and require `pdflatex` with `amsmath` and `amssymb`; Figure 3 uses Matplotlib's PDF/mathtext backend. The entire set of original long-running experiments has not been rerun in the Python 3.9 environment above.

## Full regeneration

Run from `code/`:

```bash
python experiments.py crossover two spatial incompat ladder schematic dynamics
python experiments.py ladder_means
python experiments2.py rejection multi steps diag
python refine_limit.py
python cycle_check.py
python fig1.py
python fig2.py
python fig3.py
python fig4.py
python fig_footprint.py
python fig5.py
python fig6.py
python fig7.py
```

The experiments can require substantial time and memory, particularly the rejection sampler, multiple-contact Gibbs chains, and dynamics simulations. `diag` requires `table_contact.json` and `table_incompat.json`, produced by the first experiment command. Two-node quadrature can produce SciPy integration warnings in very small tails; the validation script checks the reported values. Commands write to `code/results/` and figure scripts write to `figs/`, overwriting files with the same names.

## Scripts and random seeds

- `core.py`, `samplers.py`: response functions, graph quantities, and sampling methods.
- `experiments.py`, `experiments2.py`: main experiments and independent checks.
- `cycle_check.py`, `refine_limit.py`, `verify_results.py`: cycle experiment, refined multiple-contact moments, and selected checks.
- `fig1.py`–`fig7.py`, `fig_footprint.py`, `figstyle.py`: figures; `fig_footprint.py` produces Figure 5, while `fig5.py`–`fig7.py` produce Figures 6–8.

The original master seeds are 20261029 and 20261030 (NumPy `SeedSequence`). The rejection, multiple-contact, and time-step checks use child streams 0, 2, and 5 of seed 20261030, respectively. The incompatible cycle uses seeds 2026110101, 2026110102, and 2026110103 for noise lengths 0.1, 0.05, and 0.025. Further details are recorded in the scripts and result files.
